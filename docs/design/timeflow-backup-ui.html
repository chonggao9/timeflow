设计要点

  • 「我的」页只留一张真实状态卡，原 4 个备份入口全部收进二级页
  • 历史版本同时列出云端与本地，头部信息无需输入密码即可预览
  • 恢复三步：验密码 → 选方式（合并 / 覆盖）→ 确认；执行前自动存快照
  • 失败只改颜色与文案，不弹窗；手动备份失败才在页内给出原因
  • 清空记录移到二级页底部，需输入「清空」确认，并先存快照
  • 数据无变化时自动备份会按哈希跳过（此处仅作说明，演示中每次都会生成新版本）
