Overview

产品概述

TimeFlow 把两种截然不同的时间场景收进同一个应用：出门在外时用它记录行程轨迹，坐在桌前时用它进行番茄专注。首页一键切换双模式，行程与专注数据完全隔离、互不干扰，模式选择自动记忆。

🧭 出行打卡

轻按打卡、长按结程，自动串联成行程；积累数据后生成路线耗时洞察。

🍅 番茄专注

手势调时的全屏番茄钟，6 大分类 + 任务备注 + 8 款环境音。

🔒 隐私优先

无账号、无服务器，数据全部存在本地 SQLite；云同步仅走用户自备的 WebDAV。

☁️ 加密备份

免密加密备份文件（.tfb），支持合并 / 覆盖双模式恢复与快照回退。

Getting Started

快速上手

首次启动：阅读并同意隐私协议（不同意将退出应用），按引导授予定位权限，设置昵称（默认「时空旅行者」）。
出门打卡：首页处于「行程轨迹」模式时，轻按中央大按钮即可打卡，坐标与地名在后台自动补齐。
到达结程：在目的地长按大按钮（650ms 环形充能至满），本次行程自动结束并串联成完整轨迹。
室内专注：切换到「室内专注」模式，圆环上滑动选择时长，选好分类后开始一段番茄钟。
回顾洞察：数据积累几天后，到「洞察」页查看路线通常耗时、耗时波动与专注分布。

底部三个 Tab 为纯图标：打卡（首页）、洞察（统计）、我的（设置）。

Check-in & Trips

出行打卡

打卡与结程

  • 轻按打卡：秒级响应、先落库后补全 —— 时间戳立即记录，坐标与地名由后台异步补齐（高德定位 SDK 与系统定位并行竞速，谁先返回用谁）。
  • 长按结程：长按 650ms，环形充能动画 + 触感反馈，防止口袋误触。
  • 自动断程兜底：超过 90 分钟无打卡，当前行程自动结束，避免行程无限延长。

出行方式

打卡时通过胶囊栏选择本次移动的出行方式，共 9 种：

🚶 步行🚴 骑行🚗 自驾 🚕 打车🚇 地铁🚌 公交 🚄 高铁✈️ 飞机⛴ 轮渡

补记与纠正

  • 补记面板：忘记打卡？可补记并设置时间偏移，内置常用地点快捷 Chip。
  • 时间轴就地编辑：今日时间轴上可直接给打卡点改名、纠正出行方式、删除误打卡。
  • 轨迹地图：单次行程的打卡点连线轨迹，支持离线 SVG 拓扑图与 Google Maps 瓦片双模式。
地名反查依赖高德 Web 服务 Key，可在「我的 → 位置服务」自行配置；未配置时自动回退系统定位，打卡功能不受影响。

Focus Timer

番茄专注

计时与操作

  • 手势调时：在圆环转盘上上下滑动无级调节；预设档位 15 / 25 / 45 / 60 分钟，自定义范围 5–120 分钟。
  • 沉浸 Flow 模式：计时中隐藏底部导航、防误触，全屏只剩圆环与番茄状态。
  • 过程控制：支持暂停 / 继续；放弃需双重确认，防手滑。
  • 完成提醒：番茄成熟时发本地通知「收获一颗番茄」；保存后可一键进入 5 分钟休息倒计时。
  • 趣味状态文案：番茄随进度从「青涩 → 转红 → 快熟 → 可收获」变化。

专注分类与备注

每段专注可归入 6 大分类（各有专属颜色），并可填写任务备注（选填）：

💼 工作📚 学习🎨 创作 🧘 身心🧹 生活💡 规划复盘

历史专注可在专注记录弹窗中回溯，支持补充分类与备注。

Ambient Sound

环境音（白噪音）

专注过程中可在设置卡的横滑条上切换环境音，无缝循环播放。内置 8 款 + 无声：

🌧 雨声🌲 森林🌊 海浪 🔥 篝火☕ 咖啡厅🚆 火车 💧 溪流📻 白噪音🔇 无声

Insights

统计洞察

「洞察」页分为行程轨迹与室内专注两大统计域，时间范围可选近 7 天 / 近 30 天。

路线洞察（自动识别）

  • 系统按地点名与坐标自动聚类，识别你反复走的路线，无需手动命名。
  • 每条路线给出：通常耗时（中位数）、最快 / 最慢记录、P25–P75 波动区间、样本数。
  • 采用 IQR 方法剔除离群值，避免一次极端堵车带偏「通常耗时」。
  • 附带通常出发时段分布、耗时分布直方图、近 8 周趋势。

A→B 耗时查询

任选起点与终点，查询两地之间的历史耗时（含中途分段），回答「从家到公司通常要多久」。

行程详情与出行总览

  • 行程详情：路线拓扑简图、站点时间轴、同路线历史耗时对比（直接给出「快 / 慢 X 分钟」结论）；未命名地点有补齐 Banner 引导。
  • 出行总览：打卡总数、常去地点数、已发现路线数。

专注统计

专注次数、总时长、最长一次专注、分类分布条，支持回溯编辑。

Extras

行程小票与桌面小组件

🎫 行程小票长图

结程后生成一张仿票据样式的行程长图（Trip Receipt），汇总站点、耗时与出行方式，可保存到相册或直接分享。

📱 桌面小组件（Android Widget）

不打开应用即可一键打卡；小组件同步显示今日状态、打卡次数与最新地点。

另支持应用内检查更新（基于 GitHub Releases），发现新版本时提示下载 APK。

Backup & Restore

备份与恢复

从「我的 → 数据管理」进入备份页。备份文件为加密的 .tfb 格式，免密备份（v1.2.4 起无需记忆口令；旧版口令加密的备份仍可输入密码兼容恢复）。

WebDAV 云同步（可选）

  • 支持坚果云、Nextcloud 等任意 WebDAV 服务：填地址 + 用户名 + 应用专用密码，保存即自动测试连接。
  • 自动备份：数据变化后 60 秒防抖触发，最小间隔 30 分钟；应用切后台时补一次；打卡 / 启动时静默同步。
  • 历史版本轮转：云端保留 7 份、本地保留 5 份。
  • 防覆盖熔断：检测到远端数据条数明显减少时，自动暂停自动备份，防止坏数据覆盖好数据。

导出与恢复

  • 立即备份、导出备份文件、分享 / 另存；也可导出可读格式（CSV / JSON）。
  • 恢复支持两种模式：合并补入（推荐，只补缺失记录）与完全覆盖；恢复前显示条数对照预览。
  • 每次恢复前自动生成「恢复前快照」，不满意可一键回退。
清空所有记录属于危险操作：需手动输入「清空」二字确认，且清空前会自动保存一份本地快照。

Privacy

隐私与权限

  • 纯本地存储：所有数据保存在设备本地 SQLite 沙盒（WAL 模式），无中心化服务器、无账号体系，可完全离线使用。
  • 云同步可选且自主：仅当用户自行配置 WebDAV 时数据才离开设备，备份文件加密上传（AES-256-CBC + HMAC-SHA256 完整性校验）。
  • 权限最小化：定位权限仅在打卡时读取经纬度；相册写入权限仅用于保存行程小票长图；构建时主动移除多余媒体权限。
  • 隐私政策：中英双语完整政策（最小必要原则、第三方 SDK 披露、存储加密、数据删除机制、未成年人保护等 9 章）；首次启动强制阅读同意，不同意则退出应用。
