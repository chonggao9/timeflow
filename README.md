极简双模时间管理与轨迹记录 App（出行打卡 + 室内番茄专注），基于 Expo (React Native) + SQLite，纯本地离线优先存储，支持高德/系统双兼容定位、8款治愈环境白噪音、智能路线洞察与免密极速云备份。

## 功能特性

### 🎨 全新个性化色彩皮肤 (Skins & Themes)
- **6 套全新精选色彩皮肤**：经典珊瑚（Classic Coral）、海盐蓝（Ocean Blue）、森林绿（Forest Green）、薰衣草紫（Lavender Purple）、纸质手账（Vintage Journal）、纯黑 OLED（Pure Black OLED）。
- **正交双维外观体系**：皮肤主题（决定色调）与明暗模式（System / Light / Dark，决定基底深浅）完全独立正交叠加，状态记忆本地持久化。
- **里程碑解锁机制**：内置连续打卡天数激励机制，伴随习惯养成逐步解锁高阶典雅皮肤。
- **统一语义 Token 设计系统**：全站严格统一 `primary`、`primaryTint`、`background`、`card`、`textPrimary`、`textSecondary`、`divider` 核心 Token，告别零散杂色。

### 🍅 室内专注（番茄时钟）
- **轻触实时编辑目标**：运行中轻触顶部胶囊即可快速修改当前专注任务名称，实时同步引擎状态与落盘存储。
- **状态时序深度隔离**：彻底重构引擎状态转换流程，消除未填任务时闪现上一次历史任务文本的竞态瑕疵。
- **圆环转盘调时**：转盘手势丝滑调节专注时长，放大居中 Hero 番茄视觉，档位下移至单手拇指热区。
- **预设档位与任务备注**：支持 15 / 25 / 45 / 60 分钟常用预设一键切换；3×2 大分类网格（工作 / 学习 / 阅读 / 运动 / 冥想 / 创作）并支持自定义任务备注。
- **8 款治愈环境白噪音**：内置雨声、森林、海浪、篝火、咖啡馆、夏夜、溪流、白噪等高品质环境音，伴随专注流心。
- **全屏沉浸专注**：全屏 Flow 模式，整体对称双胶囊按钮，防误触防中断。
- **今日专注卡片与细分回溯**：顶部实时呈现今日专注总时长与多彩用途分布条，点击即可展开查看与补充历史用途记录。

### 📱 桌面小组件 (Android Widget 矩阵)
- **12 款全尺寸微件矩阵**：
  - **番茄专注系列**：完整版 (4×2)、迷你条 (4×1)、圆环版 (2×2)、番茄卡 (2×2)、深色大字 (2×2)、今日统计 (2×2)；
  - **行程打卡系列**：一键打卡 (4×2)、下一站 (4×1)、足迹拓扑 (2×2)、本周打卡 (2×2)、连续打卡 (2×2)、打卡热力 (2×2)。
- **交互式小组件指南**：全新卡片式微件说明页，支持按番茄专注与行程打卡分类检索玩法与亮点，深链直达一键体验。
- **多语言与主题联动**：桌面小组件原生支持中英双语国际化，明暗外观与 App 全局皮肤实时同步联动。
- **免开 App 瞬时打卡**：不打开 App 即可直接在手机桌面一键打卡、启停番茄钟，双端数据秒级原子同步。

### 🚀 双模式架构与模式隔离
- **双模式分段控件**：精致分段切换控件，在「室内专注」与「出行打卡」之间丝滑切换，模式状态记忆持久化。
- **数据域深度隔离**：行程轨迹与室内专注底层数据完全隔离，统计互不串联干扰。

### 🚗 极简出行打卡与轨迹记录
- **极简打卡**：秒级乐观落库，坐标 + 地名后台异步竞速补齐（高德 + 系统定位并行）；轻按记录途经点，长按结程；支持 90 分钟无打卡自动断程兜底。
- **长按 650ms 充能结程**：打卡大按钮长按增加 650ms 环形充能进度与物理触感反馈，彻底杜绝误触结程。
- **9 大出行方式**：覆盖市内日常与跨城差旅全场景（步行 / 骑行 / 自驾 / 打车 / 地铁 / 公交 / 高铁 / 飞机 / 轮渡）；支持平滑水平横滑胶囊栏与智能记忆聚焦。
- **补记抽屉面板**：独立「+补记」抽屉面板，支持时间偏移、常用地点 Chip 快捷点选与出行方式快速回溯。
- **时间轴**：今日行程与路段位移一览，支持就地改名、纠正出行方式与误打卡删除。

### 🗺️ 深度洞察与原生行程详情
- **原生行程详情页（TripDetailView）**：路线拓扑简图呈现、站点打卡时间轴、同路线历史行程耗时智能对比与中位数分析。
- **本周出行卡片**：洞察页新增本周出行统计卡片与动态路线耗时趋势。
- **未命名地点快速补齐**：智能识别无地名历史记录，顶部常驻快速补齐 Banner，支持高频地点 Chip 一触即选。
- **独立专属分栏**：洞察与历史页面顶部简化为「室内专注」与「行程轨迹」两大专属统计域。
- **线路轨迹地图**：某次行程的打卡点连成轨迹（起终点 / 站点 / 全程耗时一览），离线 SVG 拓扑图与 Google Maps 瓦片双模式。

### 💾 极简免密备份与云同步
- **免密极速备份与恢复**：彻底移除备份密码心智负担与输入交互，消除纯 JS 下 PBKDF2 重复计算延迟，实现开箱即用、秒级即时恢复。
- **条数对照预览与双恢复模式**：恢复弹窗直接提供「合并补入（推荐）」与「完全覆盖」两种模式，恢复前展示条数对照与风险提示。
- **安全快照与一键回退**：恢复前自动为本机创建安全快照；恢复完成后支持「一键回退到恢复前」，提供可靠的防丢撤销能力。
- **向下无缝兼容**：遇到旧版本历史加密备份文件，依然可输入原密码无损恢复解密。
- **WebDAV 独立云同步**：保留并完善坚果云 / Nextcloud 等云端同步，支持自动备份上传、防覆盖熔断判定与版本清理轮转。

## 平台支持

- **Android**：完整支持。集成高德定位原生模块、Google Maps 瓦片地图、Android 桌面小组件（Widget），完美适配 Android 16 与 16KB 内存分页。
- **iOS**：暂不支持。项目依赖定制的 Kotlin 原生定位模块 `modules/amap-location`，目前尚未提供 iOS 原生桥接层，请勿直接在 iOS 环境下构建运行。

## 技术栈

- **框架**：Expo SDK 53 / React Native 0.79（适配 Android API 36）
- **本地存储**：`expo-sqlite`（纯本地存储，无服务器、无账号，离线优先）
- **定位引擎**：高德开放平台定位 SDK（自定义 Expo 原生模块 `modules/amap-location`）+ 系统 (Google) 并行竞速定位
- **音频引擎**：`expo-av`（白噪音无缝循环播放）
- **桌面小组件**：`react-native-android-widget`
- **地图渲染**：`react-native-maps`（线路轨迹地图，Google Maps 瓦片，依赖 GMS 机型）

## 快速开始

> ⚠️ 本应用含自定义原生模块（高德定位 SDK），**不能运行在 Expo Go 里**，需用开发构建（development build）。

### 1. 安装依赖

```bash
npm install
```

### 2. 运行 Android 开发构建

```bash
npm run android        # 等价 npx expo run:android
```

首次运行会 prebuild 生成 `android/` 并编译原生模块，需本地已配置 Android SDK。

### 3. 打包构建

```bash
# 本地构建 release APK
npm run build:local

# 本地构建 Google Play AAB 专供包
npm run build:aab

# EAS 云端测试包（preview profile，APK）
eas build --platform android --profile preview

# 一键发版脚本（升版本 → EAS 构建 → 下载 → GitHub Release + 上传 APK）
npm run release -- --commit --push
```

## 数据与隐私说明

- 打卡记录与专注记录存储于本地 **SQLite**（`timeflow.db`），无需服务器、无需账号，数据完全归用户所有
- 位置数据仅通过高德 SDK 与系统定位采集 / 反查，不落任何第三方服务器
- 备份：记录与偏好自动生成结构化自包含备份（`.tfb`），本地沙盒自动守护；恢复时秒级免密读取，并支持恢复前自动生成快照及一键撤销回退；支持 WebDAV（坚果云/Nextcloud）双向同步与防覆盖熔断保护
- 隐私政策公开页：https://chonggao9.github.io/timeflow/privacy.html
